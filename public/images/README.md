# Fotografías

Formatos: AVIF/WebP optimizados, con variantes responsive.
Registra cada imagen en `src/data/imagery.ts` (slot `hero`, `sign`, …) indicando `status`:
`FINAL`, `TEMPORARY_STOCK` (licencia verificada, sustituir) o `PENDING_REAL_ASSET`.

Prioridad: fotografía real del rótulo circular (slot `sign`) y de consulta/despacho (slot `hero`).
Nunca etiquetar a una persona de stock como "nuestro abogado".
